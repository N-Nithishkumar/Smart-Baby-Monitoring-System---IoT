# Smart Baby Monitoring System – IoT 👶📡

The **Smart Baby Monitoring System** is an IoT-based solution designed to help parents continuously monitor their baby’s safety and activities. The system provides real-time alerts to parents whenever specific baby movements or behaviors are detected, ensuring peace of mind even when they are away.

## 📌 Features

- 👶 **Sleep Movement Detection**
  - Detects baby movements during sleep.
  - Sends an instant alert to the parent's mobile phone when the baby wakes up.

- 🔊 **Cry & Motion Detection**
  - Identifies baby crying sounds.
  - Detects any unusual movement around the baby.
  - Notifies the registered owner immediately.

- 👀 **Eye Blink Detection**
  - Detects baby eye blinking using vision-based sensors.
  - Sends notification alerts in real time.

- 📱 **Instant Mobile Alerts**
  - All alerts are sent directly to the parent’s smartphone.

---

## 🛠️ Technologies Used

- Internet of Things (IoT)
- Microcontroller (ESP32 / Arduino / Raspberry Pi)
- Motion Sensors
- Sound Sensor / Microphone Module
- Camera Module (for eye blink detection)
- Wi-Fi Module
- Mobile Notification Service (SMS / App / Email)

---

## ⚙️ System Architecture

1. Sensors continuously monitor baby movements, sounds, and eye activity.
2. Data is processed using a microcontroller.
3. Events are transmitted via Wi-Fi.
4. Alerts are sent to the parent’s mobile device instantly.

---

## 🚀 How It Helps Parents

- Provides **24/7 monitoring** of baby activity.
- Reduces the need for constant physical supervision.
- Ensures quick response during emergencies.
- Enhances baby safety using smart technology.

---

## 📦 Installation & Setup

1. Connect all sensors to the microcontroller.
2. Configure Wi-Fi credentials.
3. Upload the firmware to the controller.
4. Link the notification service with the parent’s phone.
5. Power on the system and start monitoring.
